<details>
<summary>How this page is built</summary>

<br>

The header and link plates are SVGs generated by `build/editorial.py`. No badge
services, no template. GitHub renders README images in an `<img>` sandbox with no
JavaScript, no network and no web fonts, so Instrument Serif is subset to only the
glyphs each file actually sets and inlined as a data URI. A link plate reading
"LinkedIn" carries eight glyphs, which is why the whole set is under 90 KB.

Light and dark variants are swapped with `<picture>` and `prefers-color-scheme`.
Every word of body copy stays in markdown rather than baked into an image, so it
stays selectable, searchable and readable by a screen reader.

```
python build/editorial.py
```
